# Acervo (local, fora do git)

Material bruto para o `/compilar`. **Tudo aqui é ignorado pelo git** (sigilo fiscal), exceto este README.

- `protocolos/` — consultas como chegaram (PDF/DOCX)
- `pareceres/` — pareceres finais aprovados (versão selada)
- `emendas/` — versões devolvidas pelo superior, com comentários/alterações controladas

Nomeie para casar os três: `<id>_protocolo.pdf`, `<id>_parecer.docx`, `<id>_emendas.docx`.
`<id>` pode ser só um número sequencial seu.
