# Modelo .docx

Coloque aqui `template.docx`: um parecer **em branco** com os estilos de parágrafo da casa
(título, ementa, seções, corpo, citação em bloco, assinatura), cabeçalho/rodapé e margens.

Dica: pegue um parecer real, apague o conteúdo mantendo um parágrafo de cada estilo,
e substitua dados por `[CAMPO]`. O Escriba usa os estilos, não formatação manual.
